# Eligibility before merits

1. Identify the cardholder's claim family separately from candidate network conditions.
2. Resolve the governing date and retrieve the condition version effective on that date.
3. Check every prerequisite and every invalid-dispute clause.
4. Search for pending authorizations, descriptor aliases, credits, and split clearings first.
5. Keep the cardholder outcome separate from network recovery.
6. Stop when further evidence cannot change either outcome.

Return source IDs for every finding. Never infer arithmetic in prose.
