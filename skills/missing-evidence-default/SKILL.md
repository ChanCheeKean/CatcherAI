# Missing evidence

Silence is a fact in the graph, not a reason to wait. Look for evidence requests linked to the dispute (their status, deadline and whether the deadline has passed).

1. If the deadline passed with no response, treat the missing proof as unavailable. Do not assume it would have favoured the merchant.
2. Apply the cardholder-favourable default to the part of the claim that only that proof could have answered. Facts you already have for other parts of the claim still decide those parts.
3. Separate what is proven (graph evidence), what is unproven because evidence is missing, and what is contradicted. Say which is which in the reasoning.
4. Record the missing evidence and the default you applied as a finding, so the final report can name it.
5. Do not invent evidence, and do not simulate a reply.
