# Memory hygiene
1. Search existing Memory Notes with `search_knowledge` using kind `memory_note` before writing.
2. Treat notes as leads; verify them against current graph records and applicable Clauses.
3. Write a reusable lesson through `memory_write` with graph or Clause ids as sources.
4. Supersede a stale note when evidence supports a corrected lesson; retract one when the original was wrong.
5. Merge repeated lessons when one clear note captures them, retaining sources.
6. Keep details of individual Card Members and raw speculation out of durable memory.
