# Case Notebook
1. Read `notebook_read` before starting so you can build on prior work.
2. Use `notebook_write` for one idea per entry, with at least one graph node or edge id you verified.
3. Use `fact` for a confirmed record and `hypothesis` for an explanation still being tested.
4. Use `policy_reading` for the meaning of an applicable Clause and `conflict` for opposed readings or terms.
5. Use `ruled_out` for a disproved path and `improvement_idea` for a concrete preventable gap.
6. Re-read entries before handing off; this notebook is the shared record of this run, while Memory Notes hold reusable lessons across runs.
